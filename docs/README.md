# docs/

Project documentation for the indoor AR rebuild lives here.

- `src/core/` — positioning, session and state logic shared by everything else.
- `src/providers/` — integrations with external services (e.g. Immersal).
- `src/ui/` — DOM and AR scene components.
- `src/venues/` — venue JSON loading and validation.
- `public/` — static files copied verbatim into the build.
- `legacy/` — the original GPS demos, reference only; never edited or linted.
